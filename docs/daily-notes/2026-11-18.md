# Engineering Daily Notes: 2026-11-18

## Focus: Mobile & Web UI Declutter, Modernization & Device Stability

### 1. Root Cause Analysis: Mobile UI Clutter & Cramping
- **Bottom Navigation Overload:** The previous mobile navigation bar squeezed 6–7 items (`Shield`, `Alerts`, `Incidents`, `Aadhaar`, `Research`, `Security`) onto a single bottom row. On typical phone screens (360–390pt width), each tab had less than 55pt of horizontal space, causing severe label truncation and cramped touch targets below the recommended 48pt WCAG accessibility standard.
- **Top Bar Real-Estate Waste:** A 60pt horizontal language chip scroller plus vernacular audio prompt was permanently pinned at the top of every screen, pushing critical security telemetry off-screen.
- **Dashboard Widget Stacking:** `DashboardScreen.tsx` was a continuous vertical stack of 10+ distinct boxed widgets, including a 300-line full interactive canvas document redactor, raw QR string verifier, and timer widgets competing for attention.
