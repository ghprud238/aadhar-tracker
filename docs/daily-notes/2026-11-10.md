   - **Android `AccessibilityService` Hook:** Intercepts `TYPE_VIEW_TEXT_CHANGED` in `com.whatsapp`, runs Verhoeff $D_5$ locally, and displays a floating warning overlay before message transmission.
   - **Android `BroadcastReceiver` (`SMS_RECEIVED`):** Intercepts incoming SMS PDUs with statutory permission.
   - **Custom Keyboard (IME) Extension (Android & iOS):** Intercepts keystroke buffer across all apps before text is committed, enabling real-time on-device masking.
   - **System Share Extension / Intent:** Intercepts files/photos shared into messaging apps.
   - **Meta WhatsApp Cloud API Webhook:** Server-side B2C gateway interception for messages sent to enterprise bots.
