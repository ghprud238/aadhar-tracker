### Phase 1: Dedicated Google Login Screen & Identity Authentication Integration
**User Request:** *"do we have a login screen here? If not, let's add it and make it tied to google login process"*

1. **Architecture & Existing Code Audit:**

2. **Created Google Auth Service ([`apps/mobile/src/services/googleAuth.ts`](file:///Users/dpcubed/projects/aadhar-tracker/apps/mobile/src/services/googleAuth.ts)):**

   - Implemented `buildGoogleAuthUrl()` supporting both web browser redirects and mobile deep linking (`in.suraksha.mobile://oauth`).
