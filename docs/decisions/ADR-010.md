# ADR-010: Aadhaar/PAN Assistance Before Restricted Integrations

## Status
Accepted

## Context
Direct UIDAI or Income Tax Department integration requires licensed AUA/KUA status and strict purpose clearance. Government scraping or OTP interception is illegal and unsafe.

## Decision
Initial Aadhaar/PAN features focus on protective guidance (UIDAI biometric locking guides, Virtual ID creation, official authentication history audit walkthroughs, structured user-reported incidents). Automated verification is gated until official partner authorization is secured.

## Consequences
Delivers immediate consumer protective value without regulatory violation or credential security risks.
