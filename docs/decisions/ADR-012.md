# ADR-012: Explicit Coverage and Uncertainty

## Status
Accepted

## Context
Displaying a generic "all safe" green checkmark when a provider is down or unconfigured misleads users.

## Decision
The platform explicitly displays per-source status: `healthy`, `delayed`, `unavailable`, `unsupported`, or `no_matches`.

## Consequences
Honest, transparent UI that never conflates a failed check with a clean bill of health.
