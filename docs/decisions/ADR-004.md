# ADR-004: PostgreSQL Source of Truth

## Status
Accepted

## Context
The platform requires ACID transactional guarantees for outbox events, consent records, and identity states.

## Decision
Use PostgreSQL as the primary transactional database, with strict relational integrity, composite foreign keys, and Alembic migrations.

## Consequences
Provides atomic outbox inserts, robust JSONB querying for provider checkpoints, and native Row-Level Security support.
