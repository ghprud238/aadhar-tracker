# ADR-005: Application Authorization plus Row-Level Security (RLS)

## Status
Accepted

## Context
Object-level authorization failures (IDOR) are OWASP API Top 10 risks. Application code alone may suffer regressions.

## Decision
Implement defense-in-depth: Application-level permission checks PLUS PostgreSQL Row-Level Security (`RLS`) utilizing transaction-scoped session variables (`app.current_tenant_id`, `app.current_subject_id`).

## Consequences
If an application bug forgets a WHERE tenant_id clause, RLS fails closed and blocks cross-tenant leakage.
