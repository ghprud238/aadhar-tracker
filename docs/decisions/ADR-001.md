# ADR-001: Modular Monolith with Isolated Workers

## Status
Accepted

## Context
The platform needs to balance agility, reliability, and security boundaries. Microservices with dozens of repos introduce premature operational friction.

## Decision
Build as a modular monolith in Python/FastAPI with separate deployment entry points for workers (connector-worker, notification-worker, privacy-worker).

## Consequences
Shared data models and typing in `packages/domain` without cross-service network latency, while enforcing worker privilege separation through environment configuration and network boundaries.
