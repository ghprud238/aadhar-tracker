# ADR-003: Same-Origin BFF and Server-Side Tokens

## Status
Accepted

## Context
Storing bearer access tokens in browser localStorage or sessionStorage exposes them to XSS and token exfiltration.

## Decision
Use a same-origin Backend-For-Frontend (BFF) architecture. Browsers receive encrypted, HttpOnly, SameSite=Strict cookies. Access tokens and refresh tokens are stored in the server session store.

## Consequences
Protects tokens from client scripts; requires CSRF protection on mutating endpoints and Origin header validation.
