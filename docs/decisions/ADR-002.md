# ADR-002: Managed OIDC Authentication

## Status
Accepted

## Context
Custom user credential databases are prime targets for credential stuffing and breach risks.

## Decision
Delegate user sign-in to an OIDC provider (e.g. Amazon Cognito or standard OpenID Connect) using authorization-code flow with PKCE.

## Consequences
The platform stores no user passwords. Validates tokens, handles token rotation, and enforces server-side session lifetimes.
