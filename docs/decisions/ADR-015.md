# ADR-015: No LLM Dependency in the Monitoring Critical Path

## Status
Accepted

## Context
Generative LLMs in automated monitoring pipelines risk prompt injection, non-deterministic classification, and hallucinations.

## Decision
The core monitoring, normalization, matching, scoring, and alerting pipeline uses deterministic Python code and schema rules. LLMs are never placed in the synchronous detection path.

## Consequences
Reproducible, verifiable, auditable incident analysis and zero prompt-injection risks from hostile provider text.
