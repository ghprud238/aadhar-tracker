# ADR-008: Exact Matching for Launch

## Status
Accepted

## Context
Fuzzy matching on names or partial identifiers generates false positives and misleading anxiety for consumers.

## Decision
For initial launch, only exact verified email matching is permitted. No name-only matching, domain-only matching, or last-4 digit government ID matching.

## Consequences
Eliminates false-positive noise; simplifies normalization and scoring.
