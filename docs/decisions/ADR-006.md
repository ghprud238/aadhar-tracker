# ADR-006: Transactional Outbox and Idempotent Consumers

## Status
Accepted

## Context
Dual-write problems between database transactions and message queues cause lost events or inconsistent states.

## Decision
Write business mutations and outbox event intents in a single database transaction. A dedicated outbox dispatcher publishes events to workers, where consumers enforce idempotency via `processed_events`.

## Consequences
Guarantees at-least-once delivery; consumers must be idempotent and tolerate out-of-order execution.
